# 卡车配件 AI 产品数据中心

面向卡车配件出口企业的 AI 产品数据库 MVP：把供应商资料整理成标准字段，按 OE 号、互换号、名称或照片秒级找到产品、替代件与报价。基于 Django 5.2。

需求、架构、数据字典与施工进度见 [docs/](docs/index.html)。开发约定见 [AGENTS.md](AGENTS.md)。完整的安装与运行说明将在 M20 补全。

> **演示数据声明**：`python manage.py seed_demo` 生成的产品、编号、车型与供应商报价单全部是合成数据。编号只按各品牌的书写格式随机生成，**不是真实 OE 号**，不能用于采购或报价。
